Sistema de Gestão de Cantina

O que é

Sistema interno de gestão de cantina desenvolvido com Java e Spring Boot. Permite gerir vendas, estoque, funcionários e relatórios de forma completa. Utiliza base de dados H2 persistida em ficheiro para manter os dados entre reinícios do servidor.
